# TaskFlow API & Dashboard

A lightweight task management web application with JWT authentication and PostgreSQL storage.

## Architecture
- **Backend:** Node.js Express API with modular controllers, authentication middleware, and database pooling.
- **Frontend:** Vanilla JavaScript client communicating with REST endpoints.
- **Authentication:** Token-based authentication using JSON Web Tokens (JWT).
- **Database:** PostgreSQL connection managed via pg pool.

## Features
- User registration and secure login
- Protected task management routes
- Health checks and system telemetry
